# EZStay 서비스 정책 (전체)

> 이 문서는 EZStay 서비스의 전체 도메인 정책을 정의합니다.
> 모든 코드 구현 시 이 정책을 준수해야 합니다.

---

## Domain 0: 최상위 서비스 정책

### 핵심 원칙
- 모든 금전 거래는 **결제 완료 시점 기준**으로 고정 (스냅샷)
- 상태 전이는 **순방향만 허용**, 역방향 전이 불가
- 시간 기반 정책은 **서버 시간(KST)** 기준
- 금액 계산은 **원 단위 절삭** (소수점 이하 버림)
- 모든 취소/환불은 **사유 기록 필수**

### 사용자 역할
| 역할 | 설명 |
|------|------|
| 게스트 | 방을 검색하고 계약을 요청하는 사용자 |
| 호스트 | 방을 등록하고 계약을 승인하는 사용자 |
| 관리자 | 분쟁 조정, 예외 처리, 시스템 관리 |

## Domain 1: User (회원/계정/권한)

### 회원가입
- **필수 정보**: 이메일, 비밀번호, 이름, 전화번호
- **소셜 로그인**: 카카오 로그인 지원
- **이메일 인증**: 회원가입 시 이메일 인증 필수
- **전화번호 인증**: SMS 인증 필수

### 역할 전환
- 기본 역할: 게스트
- 게스트 → 호스트 전환: 호스트 추가 정보 입력 (사업자번호, 계좌정보 등)
- 호스트 → 게스트 전환: 즉시 가능 (모드 스위칭)
- 한 계정으로 게스트/호스트 모두 가능

### 필수 정보 게이트
- **핵심 액션 시점**: 계약 요청, 결제 등 주요 액션 실행 전
- **검증 항목**: 이름, 전화번호 입력 여부
- **미입력 시**: 모달 팝업으로 입력 유도 (액션 차단)

### 계정 상태
| 상태 | 설명 | 제한 |
|------|------|------|
| 정상 | 모든 기능 사용 가능 | 없음 |
| 정지 | 관리자에 의한 정지 | 로그인 가능, 주요 기능 차단 |
| 탈퇴 | 회원 탈퇴 완료 | 로그인 불가, 데이터 보관(법적 의무) |

## Domain 2: Room (방 등록/수정/노출)

### 등록 프로세스 (5단계)
1. **기본 정보**: 방 이름, 주소(우편번호 검색), 건물 유형, 면적, 방/화장실 수, 층수, 엘리베이터 유무
2. **사진**: 최소 5장 ~ 최대 20장, 드래그 순서 변경, 메인 사진 설정
3. **요금**: 임대료(월), 관리비(월), 청소비(1회), 보증금(고정 30만원)
4. **서비스**: 편의시설 선택, EZ서비스 설정 (활성화 시 현관 비밀번호 필수)
5. **소개**: 최대 입주 인원, 체크인 시간(14:00~17:00), 체크아웃 시간(08:00~11:00), 방 설명(최소 10자)

### 방 상태
| 상태 | 설명 | 수정 가능 |
|------|------|-----------|
| draft | 작성 중 (임시저장) | 전체 수정 가능 |
| pending_review | 심사 중 | 수정 불가 |
| approved (active) | 승인 (노출 중) | 가격/편의시설/설명만 수정 |
| approved (inactive) | 승인 (비노출) | 가격/편의시설/설명만 수정 |
| rejected | 거절 | 전체 수정 후 재심사 |

### 승인 후 수정 규칙
- **수정 가능**: 임대료, 관리비, 청소비, 편의시설, 방 설명, 사진, 최대 입주 인원
- **수정 불가 (재심사 필요)**: 주소, 건물 유형, 면적, 방/화장실 수, 층수
- **진행 중 계약이 있는 경우**: 가격 변경은 다음 계약부터 적용

### 노출 조건
- 승인 상태 + 활성 상태
- 최소 사진 5장 이상
- 모든 필수 정보 입력 완료

## Domain 3: Contract (계약)

### 계약 상태 흐름
```
요청(REQUESTED) → 승인(APPROVED) → 결제완료(PAID) → 임대중(IN_PROGRESS) → 종료(COMPLETED)
                 ↘ 거절(REJECTED)
                                  ↘ 결제만료(PAYMENT_EXPIRED)
                                                              ↘ 취소(CANCELLED)
```

### 상태별 규칙

| 상태 | 전이 조건 | 시간 제한 | 액션 |
|------|-----------|-----------|------|
| REQUESTED | 게스트가 계약 요청 | 호스트 72시간 내 응답 | 게스트: 철회 가능 / 호스트: 승인 또는 거절 |
| APPROVED | 호스트 승인 | **게스트 24시간 내 결제** | 게스트: 결제 진행 / 미결제 시 자동 만료 |
| PAID | 결제 완료 | - | 상세주소 노출, 스냅샷 고정 |
| IN_PROGRESS | **입주일 도래 시 자동 전환** | 계약 기간 동안 | 옵션 추가/취소, 관리자 취소 요청(1회) |
| COMPLETED | **퇴실 확인 프로세스** | 48시간 자동 확정 | 보증금 반환, 리뷰 작성 |
| REJECTED | 호스트 거절 | - | 사유 필수, 게스트 알림 |
| CANCELLED | 취소 처리 | - | 환불 정책 적용, 사유 필수 |

### 퇴실 확인 프로세스
1. 퇴실일 도래
2. 게스트 퇴실 확인 (체크아웃 시간 이후)
3. 호스트 퇴실 확인
4. 양측 확인 완료 → COMPLETED
5. **48시간 미확인 시 자동 COMPLETED 처리**

### 주소 노출 정책
- **결제 전** (REQUESTED, APPROVED): 동/구 단위까지만 표시, 상세주소 마스킹
- **결제 후** (PAID, IN_PROGRESS, COMPLETED): 전체 상세주소 표시

### 정보 접근 권한
| 정보 | 게스트 | 호스트 |
|------|--------|--------|
| 방 기본 정보 | ✅ | ✅ |
| 상세주소 | 결제 후만 | ✅ |
| 계약 금액 상세 | ✅ (본인 결제 내역) | 정산 금액만 |
| 게스트 옵션/할인 | ✅ | ❌ |
| 호스트 수수료(3.3%) | ❌ | ✅ |
| 게스트 수수료(9.9%) | ✅ | ❌ |

## Domain 4: Pricing & Fee (가격/수수료)

### 계약 금액 구성
```
총 결제 금액 = 임대료 + 관리비 + 청소비 + 옵션 금액 + 보증금 + 게스트 수수료
```

### 수수료 체계
| 구분 | 요율 | 기준 | 계산 |
|------|------|------|------|
| 호스트 수수료 | 3.3% | 임대료 + 관리비 + 청소비 | 정산 시 차감 |
| 게스트 수수료 | 9.9% | 임대료 + 관리비 + 청소비 | 결제 시 추가 |

### 보증금
- 고정 금액: **300,000원**
- 결제 시 포함, 퇴실 확인 후 반환
- 파손/미납 시 차감 가능 (관리자 승인 필요)

### 금액 계산 규칙
- 원 단위 절삭 (소수점 이하 버림)
- 모든 금액은 KRW (한국 원)
- 세금 포함 가격 표시

## Domain 5: Option/Rental Items (옵션/부가서비스)

### 옵션 생명주기 (D-5 정책)
| 시점 | 추가 | 수정 | 취소 |
|------|------|------|------|
| 결제 전 | ✅ | ✅ | ✅ |
| 결제 후 ~ D-5 이전 | ✅ | ❌ | ✅ (전액 환불) |
| D-5 이후 ~ 입주 전 | ❌ | ❌ | ✅ (환불 정책 적용) |
| 임대 중 | 요청만 가능 | ❌ | 요청만 가능 |

- **D-5**: 입주일 5일 전 기준
- 옵션 추가/취소는 별도 결제/환불 처리
- 옵션 금액은 스냅샷에 포함

## Domain 6: Payment/Refund (결제/환불)

### 결제
- **PG사**: TossPayments
- **결제 수단**: 카드, 계좌이체, 간편결제
- **결제 시점**: 계약 승인 후 24시간 이내
- **결제 완료 시**: 스냅샷 고정, 상세주소 노출, 알림 발송

### 환불 정책
| 시점 | 환불율 | 비고 |
|------|--------|------|
| 결제 후 ~ 입주 30일 전 | 100% | 전액 환불 |
| 입주 30일 전 ~ 14일 전 | 70% | 30% 위약금 |
| 입주 14일 전 ~ 7일 전 | 50% | 50% 위약금 |
| 입주 7일 전 ~ 입주일 | 30% | 70% 위약금 |
| 입주 후 | 환불 불가 | 관리자 중재 가능 |

- 환불은 원래 결제 수단으로 처리
- 수수료는 별도 환불 정책 적용

## Domain 7: Deposit (보증금)

### 보증금 규칙
- 고정 금액: **300,000원**
- 계약 결제 시 함께 결제
- 정상 퇴실 확인 후 전액 반환

### 보증금 차감 사유
- 시설 파손 (호스트 증빙 필요)
- 관리비/공과금 미납
- 청소 불이행 (EZ서비스 미사용 시)

### 차감 프로세스
1. 호스트가 차감 사유 + 증빙 제출
2. 게스트에게 알림 및 이의제기 기간 (72시간)
3. 이의 없음 → 차감 확정
4. 이의 있음 → 관리자 중재

## Domain 8: Settlement (호스트 정산)

### 정산 금액 계산
```
정산 금액 = 임대료 + 관리비 + 청소비 - 플랫폼 수수료(3.3%)
```

### 정산 시점
- **자동 정산**: 입주일(체크인) 기준 **영업일 3일 후** 자동 정산
- 정산 완료 후 **되돌릴 수 없음** (irreversible)

### 정산 상태
| 상태 | 설명 |
|------|------|
| pending | 정산 대기 중 |
| processing | 정산 처리 중 |
| completed | 정산 완료 (호스트 계좌 입금) |
| failed | 정산 실패 (계좌 오류 등) |

### 정산 내역 표시
- 임대료, 관리비, 청소비 항목별 표시
- 플랫폼 수수료(3.3%) 차감 내역
- 최종 정산 금액
- EZ 청소 서비스 뱃지 표시 (해당 시)

## Domain 9: Dispute/Claim (분쟁/이의제기)

### 분쟁 유형
- 보증금 차감 이의
- 시설 하자 클레임
- 계약 조건 불이행
- 기타 분쟁

### 분쟁 처리 프로세스
1. 당사자가 분쟁 신청 (사유 + 증빙)
2. 상대방 알림 및 답변 기간 (72시간)
3. 관리자 검토 및 중재
4. 결정 통보 (양측 알림)
5. 결정에 따른 금전 처리

### 분쟁 신청 가능 기간
- 퇴실 후 14일 이내

## Domain 10: Communication (채팅/알림)

### 채팅 규칙
- **채팅방 생성 조건**: 유효한 계약이 존재해야 함 (contractId 필수)
- **참여자**: 해당 계약의 게스트 ↔ 호스트만 가능
- **메시지 타입**: 텍스트, 이미지, 시스템 메시지
- **계약 상태별 제한**: 취소/종료된 계약의 채팅방은 읽기 전용

### 알림 유형
| 알림 타입 | 수신자 | 트리거 |
|-----------|--------|--------|
| 계약 요청 | 호스트 | 게스트가 계약 요청 시 |
| 계약 승인 | 게스트 | 호스트가 승인 시 |
| 계약 거절 | 게스트 | 호스트가 거절 시 |
| 결제 완료 | 호스트 | 게스트 결제 완료 시 |
| 입주 안내 | 게스트 | 입주일 D-1 |
| 퇴실 안내 | 양측 | 퇴실일 D-1 |
| 정산 완료 | 호스트 | 정산 처리 완료 시 |
| 보증금 반환 | 게스트 | 보증금 반환 완료 시 |
| 분쟁 접수 | 상대방 | 분쟁 신청 시 |

### 자동 메시지
- **트리거 타입**: 계약 확정(contractConfirmed), 체크인(checkin), 체크아웃(checkout)
- 호스트가 사전 설정한 메시지 자동 발송
- 활성화/비활성화 토글 가능

## Domain 11: Time & Schedule (시간/날짜)

### 시간 기준
- **서버 시간**: KST (Asia/Seoul)
- **날짜 계산**: 자정(00:00) 기준
- **영업일**: 월~금 (공휴일 제외)

### 주요 시간 정책
| 항목 | 시간 | 비고 |
|------|------|------|
| 호스트 승인 기한 | 72시간 | 미응답 시 자동 만료 |
| 게스트 결제 기한 | 24시간 | 미결제 시 자동 만료 |
| 체크인 시간 | 14:00~17:00 | 방 등록 시 설정 |
| 체크아웃 시간 | 08:00~11:00 | 방 등록 시 설정 |
| 퇴실 확인 | 48시간 | 미확인 시 자동 확정 |
| 정산 처리 | 영업일 3일 | 체크인 기준 |
| 옵션 D-5 기준 | 입주 5일 전 | 추가/취소 제한 기준 |

## Domain 12: Admin & Exception (관리자 개입)

### 관리자 권한
- 계정 정지/해제
- 방 승인/거절/강제 비노출
- 분쟁 중재 및 결정
- 예외 환불 처리
- 보증금 차감 승인

### 관리자 개입 요청
- **임대 중 취소**: 게스트/호스트가 관리자에게 요청 (계약당 **1회만** 가능)
- **분쟁 중재**: 양측 합의 실패 시 관리자 개입
- **예외 처리**: 자연재해, 시스템 오류 등 불가항력 상황

## Domain 13: Data & Snapshot (데이터 고정/이력)

### 스냅샷 정책
- **스냅샷 시점**: 결제 완료 시
- **고정 대상**: 방 정보, 가격, 옵션, 수수료율
- **원칙**: 결제 후 방 정보 변경해도 해당 계약에는 영향 없음

### 데이터 보관
| 데이터 | 보관 기간 | 근거 |
|--------|-----------|------|
| 계약 정보 | 5년 | 전자상거래법 |
| 결제 정보 | 5년 | 전자상거래법 |
| 개인정보 | 탈퇴 후 30일 | 개인정보보호법 |
| 채팅 내역 | 계약 종료 후 1년 | 서비스 정책 |

## Domain 14: Tax & Compliance (세금/컴플라이언스)

### 세금 처리
- 호스트 수수료: 부가세 포함 (3.3% = 3% + 0.3% 부가세)
- 게스트 수수료: 부가세 포함 (9.9% = 9% + 0.9% 부가세)
- 정산 시 원천징수 해당 없음 (플랫폼 수수료만 차감)

### 컴플라이언스
- 전자상거래법 준수 (결제/환불 정책)
- 개인정보보호법 준수 (데이터 보관/삭제)
- 통신판매업 신고 의무
- 숙박업 관련 법규 준수
